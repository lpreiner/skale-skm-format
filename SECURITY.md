# Security

SKM files are untrusted binary input. Reports involving crashes, excessive
allocation, unbounded loops, malformed chunk lengths, or unsafe extraction
paths are welcome through
[GitHub's private vulnerability-reporting interface](https://github.com/lpreiner/skale-skm-format/security/advisories/new)
once enabled. Until then, open an issue without attaching sensitive or
copyrighted input and offer to provide the reproducer privately.

The reference parser is research software and the format description is
partial. Structural acceptance is not a security guarantee.
